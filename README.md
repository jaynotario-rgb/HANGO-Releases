# HANGO for Windows

HANGO is a lightweight, local-first desktop utility for downloading media you
have permission to obtain. It supports audio extraction, video downloads and
Start + Length clips using yt-dlp and FFmpeg.

## Downloads
The first distributable beta is being prepared. **No installer is published yet.**
There is no active public automatic-update feed at this time.

This repository will host Windows release packages, signed update manifests,
release notes and required third-party license/source materials. Application
source development is maintained separately.

## Planned update behavior
Install once. Download verified updates automatically and apply them on the
next launch, without interrupting an active media download. A failed update
must preserve the previous working version.

## Use
Download only media you own or are permitted to download. HANGO does not bypass
DRM, paywalls, authentication restrictions or access controls.

No accounts, advertising, analytics or HANGO-controlled media servers.
